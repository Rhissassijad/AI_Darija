**English-to-Moroccan-Darija Translator**

In this project, I am building an AI-powered web application that translates English into Moroccan Darija and supports both Latin and Arabic writing systems.

Moroccan Darija is the main language/dialect used to communicate in Morocco, and yet it has very limited standardized linguistic resources, particularly in written form. This project aims to address that challenge by developing an accessible translation tool that combines artificial intelligence, natural language processing, and linguistic rules to produce understandable, contextually appropriate translations.

The application uses a hybrid translation system that integrates a bilingual dataset, grammatical rules, and a neural machine learning model. It supports common sentence structures, verb conjugations, negation, questions, and everyday expressions. Users can translate English sentences through a responsive web interface and submit corrections to help improve the translation dataset.

Built with Python, FastAPI, React, and JavaScript, this project combines machine learning, backend development, and frontend engineering to explore practical solutions for low-resource language translation.

The project is currently under active development, with ongoing improvements focused on translation accuracy, vocabulary coverage, and more natural Moroccan Darija output.
